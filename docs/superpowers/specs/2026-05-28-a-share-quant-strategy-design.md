# A股混合自适应量化交易策略 — 设计规格书

日期：2026-05-28 | 状态：已确认

---

## 1. 项目目标

从零搭建一套适配A股实盘的完整量化交易策略系统，包含数据获取、信号生成、风控过滤、回测执行、绩效分析五大模块。系统仅供策略研究、历史回测和复盘分析使用，不包含任何实盘自动下单功能。

## 2. 核心约束

- **性能安全**：分批次拉取数据，禁止全市场一次性暴力运算，CPU/内存占用可控
- **运行安全**：所有代码加入异常捕获和超时限制，报错立刻优雅终止
- **权限安全**：不修改系统权限、注册表、环境配置，仅本地文件读写
- **交易安全**：禁止任何全自动下单代码，仅做策略设计和离线回测
- **代码质量**：模块化、注释清晰、每个文件 150-300 行

## 5. 数据层设计

### 5.1 选股池构建

1. 拉取沪深300 + 中证500成分股（去重后约750只）
2. 剔除 ST/*ST 个股（名称前缀过滤）
3. 剔除上市不满 60 个交易日的新股
4. 最终选股池约 600-700 只

### 5.2 数据拉取策略

- **分批拉取**：每周拉取 20-30 只，批次间隔 0.5 秒
- **本地缓存**：每只股票独立 CSV 文件存于 `cache/` 目录
- **断点续传**：运行时先检查缓存，仅增量拉取缺失数据
- **增量更新**：已有数据的股票仅更新最近一周

### 5.3 数据清洗

- 统一使用后复权价格
- 停牌日标记（成交量 = 0）
- 涨跌停标记（±10% 主板 / ±20% 科创创业）
- 大盘指数单独拉取：沪深300（000300）、上证指数（000001）

## 6. 信号层设计（四维共振）

四个信号独立打分（0-10），等权加总（满分40）。总分 ≥ 24（即平均6分）且大盘择时通过，触发买入。

### 6.1 均线趋势（trend.py）

| 条件 | 得分 |
|------|------|
| EMA20 > EMA60 > EMA120 三线多头排列 | +3 |
| EMA20 上穿 EMA60（金叉，近3日） | +3 |
| 收盘价在 EMA20 之上且 EMA20 斜率向上 | +2 |
| 股价距 60 日均线偏离 > 30% | -2 |

满分 8 分，归一化到 0-10。

### 6.2 量能异动（volume.py）

| 条件 | 得分 |
|------|------|
| 当日成交量 > 20日均量的1.5倍 | +4 |
| 连续3日量能递增 | +3 |
| 当日涨幅 > 2% 且量比 > 1.2 | +3 |

满分 10 分。

### 6.3 估值过滤（fundamental.py）

| 条件 | 得分 |
|------|------|
| PE > 0 且 PE < 同行业PE中位数的80%（通过akshare获取行业分类，在选股池内计算同行业PE中位数） | +4 |
| PB > 0 且 PB < 3 | +3 |
| ROE > 10% | +3 |

通过 akshare 获取最新财报数据，每周更新一次。

### 6.4 大盘择时（market_timing.py）— 总开关

| 条件 | 判定 |
|------|------|
| 沪深300 EMA20 < EMA60 | 强制空仓 |
| 沪深300 近5日跌幅 > 5% | 强制空仓 |
| 沪深300 EMA20 > EMA60 > EMA120 | 允许满仓（8只） |
| 沪深300 EMA20 > EMA60 但 < EMA120 | 允许半仓（4只） |

## 7. 风控层设计

### 7.1 止损止盈

| 规则 | 触发条件 | 动作 |
|------|---------|------|
| 硬止损 | 单笔亏损 -8% | 次日开盘卖出 |
| 移动止盈 | 盈利后从最高点回撤 6% | 次日开盘卖出 |
| 时间止损 | 持仓 > 40 个交易日无利润 | 次日卖出 |

### 7.2 仓位管理

- 等权分配，单只最大仓位 ≤ 总资金 20%
- 大盘半仓时，总仓位 ≤ 50%
- 大盘空仓时，不买入（已有持仓仍受止损约束）
- 买入最小单位 100 股（1手），向下取整

### 7.3 费率

- 佣金：万分之 2.5（双边），最低 5 元/笔
- 印花税：千分之 1（仅卖出）
- T+1制度：今日买入，最早次日卖出
- 涨跌停限制：涨停买不到，跌停卖不掉

## 8. 执行层设计

逐日循环回测：

```
for 每个交易日:
    1. 检查触发止损/止盈 → 标记次日卖出
    2. 计算大盘择时 → 确定允许仓位
    3. 如有可用资金且仓位未满 → 运行信号选股
    4. T+1撮合：次日开盘价成交
    5. 扣除费用，更新净值
    6. 记录每日快照
```

## 9. 分析层输出

1. **收益指标**：总收益率、年化收益率、年化波动率、夏普比率
2. **风险指标**：最大回撤（含区间）、最大连续亏损天数
3. **交易统计**：总交易次数、胜率、盈亏比、平均持仓天数
4. **基准对比**：vs 沪深300超额收益、信息比率
5. **图表**：净值曲线叠加图、回撤曲线、月度收益热力图
6. **操作清单模板**：回测最后一个月每日操作清单示例

## 10. 回测参数

- 回测区间：2021-06 至 2026-05（5年）
- 初始资金：用百分比收益率计算（适配任意本金）
- 基准：沪深300总回报指数
- 收益计算方式：百分比，不限定具体金额
